### 3. 修复 STITCH 从不混入音频的完整缺口（关键发现）
`src/server/generators.ts` 的 `stitchShotVideos` 此前**只把 `options.audioTimeline` 拿去算签名，从未真正混进视频**——
最终成片永远是无声的。已补 `materializeAudio()` + ffmpeg 二次 mux（`-map 0:v:0 -map 1:a:0 -c:v copy -c:a aac`），
`fake://` 占位符与不可读音频回退为保留无声成片，不炸整个拼接。

## 环境要点（复用）
- Bash 工具 PATH 会坏（`dirname: command not found`），每次调用前置
  `export PATH="/usr/bin:/bin:/c/Windows/System32:/c/Program Files/nodejs:$PATH"`。
- git 用 `"C:/Program Files/Git/mingw64/bin/git.exe" -C "E:/desktop/.../VideosBatch"`。
- 长命令（`verify:offline` ~4 分钟）用 `run_in_background`，输出重定向到**项目内**路径（`/tmp` 会被吞）。
- smoke 脚本在 `scripts/` 下，import 用 `../src/...`（不是 `../../src/`）。
