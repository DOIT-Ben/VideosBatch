# BUG-006 刷新和离开步骤丢失未保存草稿

- 状态：已闭环（本地）
- 发现时间与方式：2026-09-22，代码审查与本地隔离复现
- 严重度：P2
- 影响面：刷新和离开步骤丢失未保存草稿；不据此推断线上已发生事故。
- 证据边界：基线 a762bb5；合成测试数据、fake 执行器；未访问生产或付费 Provider。
- 治理：ADR-0003 / P3

## 现象
刷新和离开步骤丢失未保存草稿。

## 复现
代码路径：artifact 引用变化 effect 重置 draft/editing；切换 StageWorkspace 卸载编辑器。未作浏览器实测；相同内容刷新应保留为对照。

## 代码/行号证据
基线位置：`src/client/videosBatchStudio/stages/ScreenplayStage.tsx:38; src/client/videosBatchStudio/stages/StoryboardStage.tsx:47`。原本地临时探针不作为长期回归入口；修复阶段补仓库测试。

## 根因
草稿生命周期绑定临时组件和对象引用。

## 修复方案
按项目和阶段存储草稿；内容版本变化时保留草稿并阻止覆盖保存，提供明确丢弃操作。

## 验收标准
- [x] 输入后刷新/切步骤/无关会话变化保留；上游变化显示冲突；成功保存或明确取消才清除。
- [x] 定向测试、独立审查及阶段证据完成。
