# BUG-001 请求头误触发本地会话共享

- 状态：已闭环（本地）
- 发现时间与方式：2026-09-22，代码审查与本地隔离复现
- 严重度：P1
- 影响面：请求头误触发本地会话共享；不据此推断线上已发生事故。
- 证据边界：基线 a762bb5；合成测试数据、fake 执行器；未访问生产或付费 Provider。
- 治理：ADR-0003 / P1

## 现象
请求头误触发本地会话共享。

## 复现
未配置公网地址时，外部连接提供本地主机转发头可进入共享模式。原函数隔离测试 false -> true；配置公网地址为阴性对照。

## 代码/行号证据
基线位置：`src/server/index.ts:903`。原本地临时探针不作为长期回归入口；修复阶段补仓库测试。

## 根因
将请求头当作连接信任依据。

## 修复方案
仅非生产、直接回环连接、回环 Host 且无转发头允许本地共享；公网配置或非法配置均关闭共享。
